# MOON//FLOAT — ลอยกระทงออนไลน์

เว็บลอยกระทงออนไลน์สำหรับแชร์ให้เพื่อนผ่าน **ลิงก์เดียว** ทุกคนกดลิงก์แล้วเข้ามาที่แม่น้ำเดียวกันได้เลย ไม่ต้องกรอกรหัสห้องหรือสมัครสมาชิกด้วยตัวเอง

## สิ่งที่ปรับในเวอร์ชันนี้

- ใช้ลิงก์หน้าเว็บเดียวเป็นลิงก์เชิญ กดปุ่ม `COPY SHARED LINK` เพื่อคัดลอกลิงก์ส่งให้เพื่อน
- ใช้ห้องกลางเดิม `moon-crew10` ภายในระบบ เพื่อให้ข้อมูลกระทงเดิมใน Firebase ยังอยู่และไม่แยกห้อง
- ซิงก์กระทงแบบ real-time ด้วย Cloud Firestore
- แสดงเฉพาะ **15 กระทงล่าสุด** ทั้งในหน้าเว็บและ Firestore query; เมื่อมีรายการใหม่ รายการเก่าจะเลื่อนออกจากหน้าจอ แต่เอกสารเก่ายังคงอยู่ใน Firestore
- ปรับฉากแม่น้ำเป็นกราฟิก 2D มุมมองด้านบน ใช้สีแบน ลายเส้นคลื่น และกระทงทรงวงกลม พร้อมการลอย/ไหวเบา ๆ
- ยังสร้างกระทงได้หลายแบบ เพิ่มรูป คำอธิษฐาน และสติ๊กเกอร์ได้

## ตั้งค่า Firebase (ทำครั้งเดียว)

1. เปิด Firebase Console แล้วเลือกโปรเจกต์เดิมที่ใช้อยู่
2. เปิด Authentication → Sign-in method → เปิดใช้งาน **Anonymous** เพื่อให้ระบบยืนยันตัวตนให้อัตโนมัติ ผู้ใช้ไม่ต้องสมัครหรือกดล็อกอิน
3. เปิด Firestore Database และใช้ฐานข้อมูลเดิม
4. วางกฎจาก `firestore.rules` แล้วกด Publish
5. ตรวจค่า `firebaseConfig` ใน `index.html` ว่าเป็นค่าจาก Firebase Web App ของโปรเจกต์จริง (อย่าแทนค่าถ้าใส่ไว้ถูกแล้ว)
6. อัปโหลดไฟล์ `index.html` และ `firestore.rules` ไปยัง GitHub repository เดิม แล้วรอ GitHub Pages deploy
7. ส่ง URL GitHub Pages ให้เพื่อน ทุกคนจะเข้าห้องเดียวกันโดยอัตโนมัติ

## ทดลองในเครื่อง

```bash
python -m http.server 8000
```

เปิด `http://localhost:8000` หากยังไม่ได้ตั้งค่า Firebase จะเป็น Demo Mode ซึ่งข้อมูลจะอยู่เฉพาะ browser เครื่องนั้น ไม่ได้แชร์กับเพื่อน

## โครงสร้างข้อมูลและขีดจำกัด

เอกสารอยู่ที่ `rooms/moon-crew10/boats/{boatId}` มีชื่อเล่น คำอธิษฐาน รูป JPEG ที่บีบอัดแล้ว รูปแบบกระทง สติ๊กเกอร์ UID แบบ Anonymous และ timestamp โดยหน้าเว็บอ่านเรียง `createdAt` ล่าสุดก่อนและจำกัด query ไว้ 15 รายการ

**หมายเหตุ:** การจำกัด 15 รายการเป็นการจำกัดสิ่งที่อ่าน/แสดง ไม่ได้ลบประวัติเก่าออกจาก Firestore หากต้องการลบข้อมูลเก่าจริงต้องทำผ่าน Firebase Console หรือระบบดูแลแยกต่างหาก

## ข้อควรทราบ

- Firebase Anonymous Authentication ทำงานเบื้องหลัง ผู้ใช้ไม่ต้องสร้างบัญชี แต่ Firebase ยังสามารถระบุ UID ชั่วคราวเพื่อใช้กับ Security Rules ได้
- ลิงก์นี้เป็นลิงก์สาธารณะ ใครมีลิงก์ก็สามารถเข้ามาอ่านและส่งกระทงได้ ควรหลีกเลี่ยงข้อมูลส่วนตัวในคำอธิษฐานและรูปภาพ
- Firestore Rules ป้องกันการแก้ไข/ลบเอกสารจาก client และตรวจสอบชนิด/ขนาดข้อมูล แต่ยังไม่มี rate limit หรือระบบกลั่นกรองเนื้อหาอัตโนมัติ
- รูปภาพถูกย่อและบีบอัดใน browser ก่อนบันทึกลง Firestore เหมาะกับกลุ่มเล็ก
